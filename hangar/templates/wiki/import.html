Importer des fichiers

Chaque note .md déposée devient une page du wiki, et chaque PDF se lit directement dans le wiki (lecteur intégré, aussi sur téléphone). Dépose un dossier entier (un coffre Obsidian, par exemple) pour garder ses sous-dossiers : les images, PDF, sons et vidéos qu'il contient sont importés avec, et les liens [[…]] continuent de marcher.

    Résultat

      Bon à savoir

      • Un fichier qui existe déjà n'est pas écrasé, sauf si « Remplacer » est coché (l'ancien texte d'une page reste dans l'historique).
      • Les dossiers cachés (.obsidian, .trash) sont ignorés.
      • Acceptés : notes .md (jusqu'à {{ max_note }} Mo), images, PDF, audio et vidéo (jusqu'à {{ max_attachment }} Mo).
      • Les grandes photos (plus de 2000 pixels) sont réduites et recompressées, sous le même nom.
      • Un cours en LaTeX (.tex) est converti en page : chapitres, formules, théorèmes en encadrés, tableaux. Les figures TikZ ne sont pas dessinées (leur code est gardé).
      • Dans une note, ![[cours.pdf]] affiche le lecteur PDF et ![[cours.pdf#page=3]] l'ouvre à la page 3.
      • Un coffre complet se copie aussi en ligne de commande : uv run hangar wiki-import <dossier ou adresse git>.
