{{ icon('help', 17) }} Installer un fournisseur

{{ icon('database', 15) }} Un modèle open source sur ton ordinateur (Ollama)

  1. Installe Ollama depuis ollama.com (Windows, macOS, Linux) et lance-le.
  2. Dans un terminal, télécharge un modèle : ollama pull llama3.2 (léger, 2 Go) ou ollama pull qwen2.5 (meilleur pour les outils et le français).
  3. Ici, ajoute le préréglage Ollama (local) : adresse http://localhost:11434/v1, modèle llama3.2 ou qwen2.5, puis « Tester la connexion ».

Gratuit et hors ligne ; plus lent et moins précis que Claude. Pour lire des photos, choisis un modèle « vision » (ex. llava, qwen2.5vl) dans le rôle Vision. Si le modèle s’embrouille avec les outils, règle « Appel d’outils » sur « Jamais ». LM Studio, vLLM et llama.cpp fonctionnent de la même façon avec leur propre adresse.

Mémoire du modèle. Par défaut, Ollama ne garde que 4 096 jetons : avec une page ouverte, l’assistant en demande souvent plus, et Ollama oublie alors le début (consignes, début de la page) sans prévenir. Hangar t’avertit quand c’est le cas. Pour lui donner plus de mémoire (16 384 jetons ou plus, si ton ordinateur a assez de mémoire vive) :

  • dans l’application Ollama : ouvre ses réglages (Settings) et pousse le curseur Context length ;
  • ou sous Windows : menu Démarrer, « Modifier les variables d’environnement pour votre compte », ajoute la variable OLLAMA_CONTEXT_LENGTH avec la valeur 16384, puis quitte Ollama (clic droit sur son icône près de l’horloge, « Quit Ollama ») et relance-le.

{{ icon('sparkle', 15) }} Claude (Anthropic)

  1. Crée un compte sur console.anthropic.com et ajoute des crédits (paiement à l’usage).
  2. Dans Settings → API Keys, crée une clé : elle commence par sk-ant-.
  3. Ici, ajoute le préréglage Claude (Anthropic) et colle la clé (ou mets-la dans la variable d’environnement ANTHROPIC_API_KEY), puis « Tester la connexion ».

Modèle par défaut : Claude Opus 5.5 (4 $ / 20 $ par million de jetons ; une question au panneau coûte en général moins d’un centime). La clé reste dans la base de Hangar et n’est jamais affichée en entier.
