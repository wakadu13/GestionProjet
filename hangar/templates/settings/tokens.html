Exemples

# Lister les projets
curl -H "Authorization: Bearer hgr_…" {{ request.host_url }}api/v1/projects

# Créer un ticket
curl -X POST -H "Authorization: Bearer hgr_…" -H "Content-Type: application/json" \
     -d '{"title": "Relancer le DPO", "priority": "high", "target_date": "2026-11-15"}' \
     {{ request.host_url }}api/v1/projects/1/issues

# Python
import requests
h = {"Authorization": "Bearer hgr_…"}
tickets = requests.get("{{ request.host_url }}api/v1/projects/1/issues", headers=h).json()["issues"]

Points d’accès : GET /api/v1/me, GET /api/v1/projects, GET|POST /api/v1/projects/<id>/issues (filtres state_group, assignee, limit), GET|PATCH|DELETE /api/v1/issues/<id>, GET|POST /api/v1/issues/<id>/comments.
