Hangar {{ version }}

Gestion de projet et d’équipe, 100 % locale — inspirée de Plane.

Fonctionnalités

  • Tickets : états personnalisables, priorités, assignés multiples, étiquettes, dates, estimations, sous-tickets, relations (bloque / bloqué par / lié / doublon), liens, pièces jointes, commentaires avec réactions et mentions, historique complet, temps passé.
  • Vues : liste, tableau kanban, tableur avec actions groupées, calendrier, Gantt — filtres, regroupements, tris, vues enregistrées.
  • Cycles (sprints) avec burndown, modules, intake (triage des demandes), pages (wiki markdown, modèles, versions, import Word).
  • Équipe : rôles, profils, charge de travail hebdomadaire, absences, analytique personnalisée.
  • Notifications, favoris, pense-bêtes, palette de commandes (Ctrl+K), raccourcis clavier, thème sombre.
  • Données : import/export Excel, CSV, JSON, Markdown, iCalendar ; sauvegardes ; API REST avec jetons.

Technique

Python · Flask · SQLAlchemy · SQLite. Aucune ressource externe : l’application fonctionne hors connexion.
