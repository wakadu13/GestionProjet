Partager sur le réseau local

Pour que les autres membres de l’équipe se connectent depuis leur ordinateur sur le même réseau (Wi-Fi, réseau de l’école), lance Hangar avec :

uv run hangar run --host 0.0.0.0

L’adresse à leur communiquer s’affiche dans le terminal (ex. http://192.168.1.20:5000). Le pare-feu doit autoriser le port 5000.
