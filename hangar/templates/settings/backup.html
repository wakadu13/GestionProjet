Sauvegardes

Deux sortes de sauvegarde :

Sauvegarde complète (.zip) : tout ce qu’il faut pour repartir sur une autre machine. La base (projets, tickets, agenda, progression des QCM, conversations avec l’IA, comptes, réglages), le coffre du wiki (cours, PDF, images, sets de QCM){% if vault_ailleurs %}, y compris quand il est ailleurs ({{ vault }}){% endif %}, l’historique du wiki, tes sets de QCM personnels, les copies corrigées, les pièces jointes, les emplois du temps importés et la clé des notifications.

Sauvegarde de la base (.db) : la base seule. Elle se restaure en un clic ici, mais sans le wiki, les sets de QCM, les copies ni les pièces jointes.

Ne sont jamais dedans : les anciennes sauvegardes et les e-mails de la boîte d’envoi locale (outbox). Les mots de passe des comptes n’y sont jamais lisibles.

Restaurer une sauvegarde complète

  1. Arrête Hangar (Ctrl+C dans son terminal).
  2. Décompresse le .zip dans le dossier des données {{ data_dir }}, en remplaçant les fichiers existants (supprime d’abord hangar.db-wal et hangar.db-shm s’ils existent).
    3. {% if vault_ailleurs %}
  3. Copie le contenu du dossier vault de l’archive dans ton coffre : {{ vault }}.
    4. {% endif %}
  4. Relance Hangar.

Le fichier LISEZMOI.txt de l’archive rappelle ces étapes. Une sauvegarde de la base (.db) se restaure, elle, avec le bouton « Restaurer » ci-dessus.

Autre export

{{ icon('code', 14) }} Export JSON des projets (Travail) Fichier lisible des projets, tickets (avec assignés, étiquettes et modules), pages et commentaires. Ce n’est pas une sauvegarde : il ne contient ni l’agenda, ni les QCM, ni le wiki.

En ligne de commande

uv run hangar backup --complet --vers E:\Sauvegardes --garder 10

Crée une sauvegarde complète sur une clé USB ou dans un dossier OneDrive et ne garde que les 10 dernières : pratique dans le Planificateur de tâches de Windows. Sans --complet, seule la base est copiée ; --sans-secrets retire le mot de passe des e-mails et les clés d’API.
